# 02. STEP 1：基本的なGNN

## 1. このSTEPで実装したもの

連続する2フレームの最明点（前フレーム N 個、今回 M 個）を対応付ける、最も単純なGNN。
位置予測（速度・カルマンフィルタ）は使わず、前フレームの位置をそのまま基準にする。

| 機能 | 実装 |
|---|---|
| 座標管理 | `Detection::position`（`Eigen::Vector2d`） |
| ユークリッド距離 | `GNNAssociator::computeDistanceMatrix()` |
| コスト行列 | `Eigen::MatrixXd`（N×M） |
| ゲーティング | `GNNAssociator::computeGate()` |
| 最適割り当て | `solveGatedAssignment()` → `HungarianSolver::solve()` |
| 結果・未割り当ての出力 | `AssociationResult`, `printAssignment()` |

## 2. 数式とコードの対応

### 2.1 ユークリッド距離

$$
d_{ij} = \sqrt{(x_i - x_j)^2 + (y_i - y_j)^2} = \lVert \mathbf{p}_i - \mathbf{z}_j \rVert_2
$$

```cpp
// step1_basic_gnn/GNNAssociator.cpp
distance(i, j) = (references[i] - detections[j].position).norm();
```

`Vector2d` 同士の引き算で差のベクトルを作り、`norm()`（2-ノルム = 長さ）で距離にする。
`squaredNorm()` を使えば平方根を省けるが、ゲート半径を px で直感的に指定できるよう距離そのものを使った。

### 2.2 ゲーティング

$$
g_{ij} = \begin{cases} \text{true} & (d_{ij} \le r_{\text{gate}}) \\ \text{false} & (\text{それ以外}) \end{cases}
$$

```cpp
return (distance.array() <= config_.gateDistance).matrix();
```

Eigen の `Matrix` は線形代数用（`*` は行列積）、`Array` は要素ごとの演算用（`*` は要素積、比較もできる）。
`.array()` で Array として見て要素ごとに比較し、結果の bool 配列を `.matrix()` で `GateMask`
（`Eigen::Matrix<bool, Dynamic, Dynamic>`）に戻している。コピーではなく「見方」を変えるだけなので軽い。

### 2.3 未割り当てを許す割り当て問題（GNN の目的関数）

トラック（行）i と最明点（列）j の割り当てを $a_{ij} \in \{0, 1\}$ として、

$$
\min \; \sum_{i,j} c_{ij} a_{ij} \;+\; c_{\text{miss}} \cdot (\text{未検出トラック数}) \;+\; c_{\text{fa}} \cdot (\text{未割り当て最明点数})
$$

$$
\text{制約：} \sum_j a_{ij} \le 1, \quad \sum_i a_{ij} \le 1, \quad g_{ij} = \text{false} \Rightarrow a_{ij} = 0
$$

割り当てた組の数を k とすると、目的関数は

$$
N c_{\text{miss}} + M c_{\text{fa}} + \sum_{(i,j)\text{ 割り当て}} \bigl( c_{ij} - (c_{\text{miss}} + c_{\text{fa}}) \bigr)
$$

と書き直せる。第1・2項は定数なので、**組 (i, j) を割り当てると得になるのは $c_{ij} < c_{\text{miss}} + c_{\text{fa}}$ のときだけ**であり、
解に影響するのは2つのコストの「和」だけである。本サンプルでは和をゲート半径と同じ 30 px（15 + 15）にしている。

> 資料（p.18）は「未対応観測コスト 0」、HTML は「未割当トラック = ゲート半径+1、未割当観測 = 0」としている。
> 上の式から分かるとおり和だけが効くので、これらも正しい設定である（和がゲートより大きいので、ゲート内の組は常に割り当てた方が得になる）。

この問題は、ダミー行・列を加えて正方行列にし、ハンガリアン法で解く（[05_hungarian.md](05_hungarian.md)）。

## 4. STEP 1 の限界

- 前フレームの位置を基準にしているので、目標が速く動くとゲートから外れる（ゲートを広げると誤対応が増える）。
- 1フレーム未検出になると、次のフレームでは基準点自体がなくなり、対応が途切れる。
- 「同じ目標である」という情報（ID）がフレームをまたいで残らない。

→ STEP 2 でトラック（ID・速度・状態）を導入し、予測位置で対応付ける。
